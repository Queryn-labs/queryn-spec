# osnova-spec

Открытая спецификация folder-based формата проекта Osnova.

## Статус

Стартовая основа спецификации.

## Лицензия

Репозиторий использует смешанную схему лицензирования:

- Текстовая документация распространяется по Creative Commons Attribution 4.0 International.
- JSON Schema, примеры и машинно-читаемые файлы распространяются по MIT License.

Подробности описаны в `LICENSE.md`.

## Формат проекта

Минимальный проект Osnova - папка со следующей структурой:

```text
project/
  osnova.json
  notes/
  assets/
  .osnova/
```

Расширенный проект может включать:

```text
project/
  osnova.json
  notes/
  assets/
  cards/
  graph/
  ai/
  .osnova/
```

## Команды

Для стартовой версии спецификации build step не требуется. Потребители схем должны загружать файлы из `schemas/`.

## Связанные репозитории

- `osnova-docs` описывает продуктовые и архитектурные решения.
- `osnova-core` реализует TypeScript-валидацию и project primitives.
- `osnova-desktop` читает и записывает проекты, соответствующие этой спецификации.
- `osnova-plugin-sdk` может открывать операции формата проекта для плагинов.

## Правила участия

Изменения формата проекта должны одновременно обновлять документацию, схемы и примеры. Обратно несовместимые изменения требуют ADR в `osnova-docs`.
