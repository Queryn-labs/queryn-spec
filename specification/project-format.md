# Формат проекта Osnova

Проект Osnova - директория на диске. Эта директория является редактируемым источником истины.

## Минимальная структура

```text
project/
  osnova.json
  notes/
  assets/
  .osnova/
```

### `osnova.json`

Manifest проекта. Он идентифицирует проект, объявляет версию формата и хранит метаданные уровня проекта.

### `notes/`

Markdown-конспекты. Конспект может содержать YAML frontmatter. Обычный Markdown без frontmatter остается допустимым содержимым.

`notes/` может содержать вложенные папки. Вложенные папки являются частью пользовательской структуры проекта и должны оставаться обычными директориями.

### `assets/`

Пользовательские файлы, на которые ссылаются конспекты, карточки или другие данные проекта.

`assets/` может содержать вложенные папки. Файлы остаются обычными файлами на диске; приложение не должно требовать отдельной базы данных для их просмотра или переноса.

### `.osnova/`

Application metadata, кеши, индексы и производное состояние. Проект должен оставаться понятным, если эта директория удалена и пересобрана.

## Расширенная структура

```text
project/
  osnova.json
  notes/
  assets/
  cards/
  graph/
  ai/
  .osnova/
```

### `cards/`

Структурированные учебные карточки в виде JSON-файлов.

### `graph/`

Связи между конспектами, карточками, файлами и другими сущностями проекта.

### `ai/`

AI-связанные артефакты, которые пользователь явно сохраняет в проект. Runtime caches должны оставаться в `.osnova/`.

## Ссылки MVP

Markdown-конспекты могут ссылаться друг на друга через wiki-links:

```text
[[Название статьи]]
[[папка/название-статьи|Понятный текст]]
```

Markdown-конспекты могут ссылаться на вложения через обычные Markdown-ссылки на project-relative путь:

```text
[diagram](assets/diagram.png)
[archive](assets/source/source.zip)
```

Эти соглашения не расширяют `osnova.json`. Они описывают совместимый рабочий слой поверх обычного Markdown и обычных файлов проекта.

## Архивный транспорт

Будущий формат `.osnp` - архивный транспорт для папки проекта. Он должен сохранять структуру папки и manifest. Он не является основным форматом редактирования.
